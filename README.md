# IRBI — сайт prelaunch

Публічна prelaunch-версія сайту сервісу прибирання IRBI у Чернігові.

## Поточна роль сайту
- дає IRBI публічну веб-адресу для підключення зовнішніх сервісів, зокрема HubSpot;
- показує актуальну модель послуг і робочий прайс v1.0;
- пояснює майбутній клієнтський шлях і стандарти якості;
- містить демо-калькулятор вартості;
- чесно позначає, що сервіс ще готується до запуску.

## Реалізовано
- адаптивний лендинг;
- 4 типи прибирання;
- актуальна таблиця цін;
- калькулятор за кількістю кімнат;
- основні додаткові роботи;
- правила для заселення/виселення та прибирання після ремонту;
- prelaunch-форма інтересу з локальним збереженням у браузері;
- FAQ і опис цифрового контролю замовлення.

## Наступні етапи
1. Підключити HubSpot і CRM-поля.
2. Замінити локальну prelaunch-форму на реальну CRM-форму/API.
3. Підключити Supabase для реальних заявок.
4. Додати політику конфіденційності, оферту й правила скасування.
5. Підключити аналітику та consent.
6. Перед запуском повторно перевірити прайс і домен.

## Хостинг
Рекомендовано GitHub Pages на етапі prelaunch. Перед запуском можна підключити власний домен без перенесення коду.
