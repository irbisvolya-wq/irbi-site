# IRBI — MVP сайта

Первая рабочая демо-версия сайта клинингового сервиса IRBI.

## Что уже работает
- адаптивная верстка для телефона и компьютера;
- калькулятор стоимости;
- выбор типа уборки;
- доп. услуги;
- дата и время;
- оформление демо-заказа;
- сохранение заказов в LocalStorage;
- демонстрационный личный кабинет;
- блок подписки;
- FAQ.

## Как запустить
Просто откройте файл `index.html` двойным кликом в браузере.

Для публикации можно загрузить папку на Netlify, Vercel, GitHub Pages или любой обычный хостинг.

## Что нужно для production-версии
1. Backend и база данных.
2. Авторизация клиента.
3. Кабинет клинера.
4. Админ-панель.
5. Реальные платежи.
6. SMS / email / push-уведомления.
7. Карта и проверка зоны обслуживания.
8. Политика конфиденциальности, оферта и правила отмены.
9. Реальные тарифы.
10. Аналитика и CRM.
